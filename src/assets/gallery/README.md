# Gallery demonstration imagery

These three original images were generated with OpenAI image generation for this
fictional website. They are not stock photographs, real customer homes, or evidence
of completed work. No third-party photo attribution is required. Do not describe
these images as verified service results.

- living-room.png: imagined cream-and-sage living room
- kitchen.png: imagined white-and-oak kitchen
- bathroom.png: imagined bathroom with an oak vanity

The GalleryCard component uses Astro Image to produce responsive WebP derivatives
with explicit dimensions. Only the first photo loads eagerly. Original PNG sources
are kept here for future customization; they are not copied to the public directory.

Edit src/config/gallery.ts to replace images, captions, and alt text together. Before
using third-party replacements, verify usage rights and record source and license.
